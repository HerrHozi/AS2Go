PHASE 04

Password Spray

This phase demonstrates password spraying against Active Directory accounts in the selected lab scope, showing how weak passwords can provide an initial foothold.

What this phase shows

Reviews forest password policies and account lockout thresholds, selects a domain or forest scope, and tests configured password candidates. Preview stays offline; Safe Mode allows the phase to be skipped only.

Security lesson

Account lockout alone does not eliminate password spraying. Reduce weak passwords, monitor authentication failures across accounts, and investigate successful sign-ins that follow suspicious attempts.
