PHASE 07

Privilege Escalation

This phase explores how stolen Kerberos tickets, weak service-account passwords, or a vulnerable certificate template can increase an attacker's access in the authorized lab.

What this phase shows

Offers Pass-the-Ticket, Kerberoasting, ESC1 certificate-template abuse, and a PsExec workflow running as local SYSTEM. Overpass-the-Hash and memory credential theft remain reserved menu options. Local SYSTEM access does not by itself confer domain administrator rights.

Security lesson

Separate credential acquisition from its use and validate the resulting permissions. Protect service-account passwords, review AD CS configuration, and limit privileged logons to trusted systems.
