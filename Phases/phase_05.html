PHASE 05

Initial Access

A compromised domain account provides an entry point into the environment. This phase reviews the current account context and local administrator status before the scenario continues with reconnaissance.

What this phase shows

Current Active Directory user information, including domain, password policy and group memberships, alongside local administrator membership and token elevation status. Safe Mode skips the Active Directory user-information lookup.

Security lesson

Valid credentials can give an attacker a foothold. Review the account's permissions and investigate unusual sign-ins; successful authentication alone does not imply administrative access.
